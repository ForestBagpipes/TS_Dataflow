# 方法

## 问题设定

语料是窗口的集合，每个窗口是定长的实值序列。提议者是任意这样一种程序：给定一个窗口，输出一个有序的候选编辑序列，其中一次编辑由一个算子及其参数构成。提议者不属于本文的贡献，全文将其视作黑盒，这正是同一个验收层能够套在不同提议者外部的原因。

验收层接收该序列，逐条决定什么被提交。它从不提议，也从不重排。

## M1 行为探测及其度量对象

冻结预测器在此充当验证器，而非被治理的对象。给定一个窗口，探测返回十四个信号构成的向量，覆盖若干视界上的预测误差、掩码下的重构稳定性、对输入扰动的敏感度、内部表示跨层的动态，以及后端之间的分歧。所有信号都相对一个在任何编辑之前就固定的参考尺度计算，从而使得一次平滑编辑无法缩小它自己的分母。

同类校准把原始向量转换为可比的分数。对统计画像为 p_i 的窗口 i，在画像空间中以最近邻取出同类群，校准后的偏差为

    z_i = (b_i - c_i) / s_i

其中 c_i 与 s_i 是该同类群的稳健中心与展布。标量行为风险是一个固定的加权和，r_i = z_i 点乘 w。

**该量究竟度量什么，由实证确立而非假定，而答案不是数据质量。** 它度量的是可预测性，且可分解为两个近似可加的因子，水平定位不确定性与局部形状不可预测性。设计与数字见 E4 节。对方法的直接后果是 r_i 不能作为验收的唯一依据，这正是 M2 中采用合取的动因。

## M2 执行时的接受规则

设 x 为工作副本，a 为一次编辑。该编辑先作用于沙箱副本得到候选 a(x)，随后计算三个量。

    delta U (a)     由探测给出的编辑后减编辑前的模型效用
    D (x, a(x))     结构距离，定义见下
    R (a)           提交风险，由关于这次编辑本身的证据给出

当且仅当

    Accept(a) = 1[ delta U (a) > epsilon 且 D(x, a(x)) < tau 且 R(a) < eta ]

时提交该编辑，否则回滚，x 保持不变。该层具有两条性质。

**非阻塞。** 在任何状态下至少有一个动作可行。恒等动作原样返回工作副本，因此其效用差为零、结构距离为零、代价为零。它因此永远不会被结构条件或风险条件否决，而效用条件只作用于改动性动作。可行动作集永不为空，故该层不会死锁。这也是一个窗口永远可以被原样返回的原因。

**最小干预，部分成立。** 在我们语料上被否决的编辑中，若以未受污染的原序列离线判定，有 26.3 百分比本来会改善窗口。此处给出数字而非宣称性质成立。两个条件表现不同：效用条件在其所否决的编辑中误伤 29.7 百分比，结构条件为 19.7 百分比。

### 结构距离

D 是各分量项的有界聚合，其权重取决于算子是局部的还是全局的。局部算子声明它所触及的区域，并在该区域之外按逐点形状、极值、补丁一致性与足迹大小接受判定，另加下述展布项。全局算子按构造改写每一个点，因此按频谱的信号带、趋势、季节性、记忆与尾部接受判定。

展布项的存在源于一次实测失效。仅在局部算子自行声明的足迹之外判定它，等于允许它删除任何它声明的东西。十个干净窗口的百分之九点据被编辑，失去了百分之九十六的方差，而结构距离仅为 0.037，阈值为 0.12，因为在声明的足迹之外没有任何东西移动过。该项是编辑前后分块稳健尺度之比的对数，对称设计使得放大方差与移除方差代价相同，且在整个窗口上计算，这正是足迹豁免无法掩盖的那一个量。

### 用有限样本保证校准 tau

阈值不由手工选定。固定目标水平 alpha 与损失

    L_i(tau) = 若窗口 i 的结果可测量地劣于其输入则为 1，否则为 0

以相对未受污染原序列的归一化误差度量。该损失有界于单位区间，这正是保证所要求的，且它没有可供选择的自由参数。

给定 n 个与部署数据可交换抽取的校准窗口，以及一个有序的候选阈值网格，该程序返回其修正经验风险满足目标的最大阈值，

    ( n R_hat(tau) + B ) / ( n + 1 ) <= alpha

其中 B 为损失上界。该修正正是把 n 个校准点上的平均转化为新样本点上期望之界的那一步。所得阈值满足 E[ R(tau) ] <= alpha。

该推导假设诸阈值构成嵌套族，其经验表现是单调的风险曲线。**我们验证这一点而非假定它。** 当校准风险曲线非单调时，程序回退到采用 Bentkus p 值的固定序列检验，从最保守的阈值起沿有序网格前行，在第一个无法拒绝的假设处停止。该做法在不把水平摊分到整个网格的前提下控制族错误率，且只要求顺序预先固定。

该程序有两条性质值得写明，因为它们界定了它所交付的内容。存在一个下界：网格中最保守的阈值本身已经产生某个非零的损害率，因此低于该下界的目标无解，程序正确地返回可用的最保守阈值。另外，该保证以可交换性为条件，而对其违反情形我们予以测量而非回避。

## M3 不变量规约

本工作未展开。结构距离内部的分量权重由手工设定，参考了实验中的失效分析，但并非从一份关于何者必须被保持的规约推导而来。这一点写在局限一节，而非作为一项设计选择呈现。

## M4 可预测性剥离

既然 M1 确立了行为风险度量的是可预测性，显而易见的校正就是估计可预测性并将其移除。六个代理量仅从序列本身计算，不调用任何模型：谱熵、谱平坦度、样本外线性自回归拟合、持续性误差、一阶差分自相关与样本熵。将行为风险对这些代理量作回归并取残差。该回归不使用任何标签。

这一校正有效，但不充分。它把语料 AUROC 从 0.468 提到 0.551，配对改善 0.083，区间 0.060 到 0.108，并且消除了干净不可预测数据全部四种生成形态上的误报，从 0.705 至 0.760 降到 0.504 至 0.527。它同时把水平位移的检出从 0.495 降到 0.375，平线从 0.576 降到 0.463，重复从 0.573 降到 0.501。

这两个方向是同一件事。对该信号而言，源自水平位移的不可预测与源自序列结构的不可预测是同一个量，因此移除该混杂就是把干净数据上的误报转换成位移数据上的漏检。**不存在只作用于信号本身而能同时消除两种错误的操作，这正是引入一个从不询问模型的第二证据源的论据。**

因此该模块定位为诊断性的。残差是否进入验收路径，由一项判据预先固定的接入测试决定：受保护层的编辑数必须下降，且修复的相对退化不得超过百分之十。

## 四个模块合起来是什么

M1 指出验证信号不可靠，并精确指出不可靠在哪里。M4 量化其中可靠的部分，并表明校正它是以一种错误换另一种错误。M2 是对此的回应：一个完全不询问模型的条件，在执行时逐条施加于每次编辑，其阈值携带一条明确陈述的保证。M3 是本应取代该条件内部手工权重的东西，留待后续。
