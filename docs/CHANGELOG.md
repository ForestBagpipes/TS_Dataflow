**第三批，主线重构**

诊断出的问题是同一个观察在摘要、引言开头、自动化段、两族评述、挑战一与图注中讲了五遍，方法在摘要、引言与贡献列表中复述了三遍，而三重挑战被并列呈现，掩盖了后两者是第一个问题被特定方式回答之后才出现的推论。

确定的主线是，一次修改是否有害取决于被修改的那段数据，不取决于修改本身，因此无法在执行之前判定。本文把判定推迟到执行之后，并把执行放在副本上使判错的动作可以撤回。安全与学习由此出自同一个决定。
