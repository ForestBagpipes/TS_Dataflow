# v55 实施偏差与验收记录（2026-09-23）

依据 `docs/v55_plan_20260923.md`。本文件记录实现与规划之间的差异，以及发现差异后必须重算的范围。主集 TEST 自 v46 起参与过设计，仍只作探索结果。

## D-01 来源均值的权重

规划定义的 $m_{s,a}$ 是来源 $s$ 的回放库实现效用均值，且明确要求与 Source Fixed 使用同一个量。首次 v55 实现先把每个 parent 的多个记录合并，再对 parent 等权平均；现有 `scripts/v53_source_fixed.py::source_fixed_policy` 则直接对该来源的所有合法回放记录求均值。两者不等价，因各 parent 的合法记录数可能不同，`lambda=inf` 因而不能准确解释成 Source Fixed 使用的均值。

现按已登记定义修正为**记录均值**。LOPO 选参时从分子和分母同时移除当前 parent 的全部记录。局部邻域的 `n_eff` 仍按不同 parent 计数，保持 v54 的冻结语义。修正后必须重跑三骨干的选参、校准、六块评估、消融和统计，不能混用首次 v55 数字。

来源均值相同仍不等于完整策略相同。Source Fixed 每来源预选一个动作，该动作在某请求不合法就回 KEEP；`lambda=inf` 的决策层在该请求会尝试来源均值次高的其他合法动作。若最高均值为负，正分执行门也会回 KEEP，而现有 Source Fixed 仍强制使用修复。修正后的 Bolt TEST 中，Source Fixed 的干预率为 82.6%，来源均值消融的干预率为 100%；两者 MASE 分别为 1.360247 与 1.357001。故论文只能称 `lambda=inf` 把**效用估计**退化为来源均值，不能称完整部署策略等同 Source Fixed。

## D-02 保形门在极小校准集上的回退

契约测试发现：如果有限阈值均无法满足 `alpha`，首次实现把阈值设置为校准集最高分的下一个浮点数。未来请求可有更高分，所以该回退并非真正的全 KEEP。现改为无限阈值，保证后续所有请求均 KEEP；其风险因规则恒为零，记录为零。序列请求不天然可交换，且指标裁剪于 1 MASE，论文只能陈述对应条件下的名义保证与实际未裁剪损害，不能声称无条件控制。

## D-03 主行与风险阈值的关系

当前评估脚本的 `FULL_INTROACT` 行固定使用 $\tau=0$。校准的 `CONFORMAL_A*` 行另报不同 $\alpha$ 下的阈值、实际损害和精度；在主集上不能把主行直接称为“按某个 $\alpha$ 校准的规则”，除非预先指定该 $\alpha$ 且阈值恰好与主行一致。`CROSSFIT_A*` 还从同一 TEST 块另一半 parent 的已知标签校准，只能作离线回测，不能充当未触碰的前瞻确认。论文需把三类行的角色写清楚。

## D-04 确认集 SAITS 拟合次数与审计

原 `v54_confirmatory_saits.py --mode full` 在每个来源的 `train_eval`、`test`、`test_m2`、`test_m3` 上各调用一次 `fit_and_impute`，实际是每来源四次拟合，而其文档与规划要求在整个 bank 上拟合一次并复用于所有评估块。原队列已在运行，不中断；原输出保留用于审计。新增 `v55_confirmatory_saits_once.py` 每来源只拟合一次，合并四块查询做一次推理，写入隔离的 v55 回放目录。确认集 v55 的冻结、预测和测试评估都须读取该目录；未跑完单模型版本前，不能把 v54 重复拟合结果写成独立确认。

原审计把结构性不适用的动作数误当模型失败数，导致有效回放可能被误报失败。现保留已登记取消 BRITS/CSDI 的原有配置，对预测核验实际模型失败和已适用动作的预测哈希。未通过审计不得开启确认 TEST 评价。
确认评价入口的条件也已改为必须看到 `all_passed=true`，并增加测试证明即使审计文件标为已完成但其中有失败项，也会在读取 TEST 前拒绝。

## D-05 PSW-I Traffic 报告权限故障

并行重试实际生成了 Traffic 的四块修复档案，但结束写报告时遇到旧失败报告由 `root` 所有、`vipuser` 无写权限。先只修正两份报告的所有权，再用 `v55_recover_pswi_traffic.py` 对四块档案逐一核验：键集合与冻结输入清单完全相同，分别覆盖 24/48/48/48 个请求；观测值不变，隐藏值均有限。旧失败报告原样归档，新报告明确标注由现存完整档案审计恢复。后续合并仍需对全部来源再做一次完整覆盖与内容检查；不能仅凭此恢复报告宣称 PSW-I 主网格已完成。

## 当前事实与写作边界

- 首次 v55 一倍标准误选参：Bolt 的 `lambda=0`，Chronos-2 与 TimesFM 的 `lambda=4`。因此池化没有在三骨干上都被选中。
- 首次 TEST 结果中，Bolt 的 IntroAct-TS 为 1.382575，Source Fixed 为 1.360247，配对差 +0.022328，95% 区间 [+0.004429,+0.043174]，Holm 后 p=0.04。这个结果与原规划预期相反。D-01 修正后以重算为准。
- 不能把“网格包含 `lambda=0` 和 `lambda=inf`”推断成 TEST 上对两者都不差。一倍标准误规则与损害率约束也不保证训练侧精度严格不差于它们。
- 确认集的 Solar、US_Term_Structure 曾在 v43 的开发阶段出现。可以核验并表述当前确认 TEST 时间区间未用于 v55 选参；不可未经审计就称这两个来源从未参与过任何开发。
