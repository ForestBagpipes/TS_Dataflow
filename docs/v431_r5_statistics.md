# r5 统计口径

入口 `scripts/v431_r5_statistics.py` 只读取已导出的 `evaluation/*/decisions.json`、可选 `common_decisions.json` 和 `mechanism_rows.json`，不载入预测模型、不拟合、不访问目标归档或 calibration/test。

共同完整方法采用 source→parent→variant 逐层等权。配对描述区间复用已登记 2000 次、seed 101 的 source 固定、来源内按原始起点排列的相邻双 parent 块 bootstrap；单一来源 parent 与反复使用 DEV 的限制保留。区间不作为确认检验。

固定轨迹几何对照强制检查每窗 `queried_actions` 完全一致，分别报告全覆盖与至少三个不同预测的子集；少于三个不同预测不能支持高阶几何贡献。自适应轨迹单独报告，不能将其查询集合变化归因于投影模块。历史证据对照保留额外 H 费用，不能称与当前响应同成本。

同时导出收益向量平方误差、成对约束违反、投影激活、排名变化、正确切换收益、错误切换损失、MASE、求解状态/gap/费用、尾部退步、超支与失败。分组指标保留完整来源权重；求解器调用总耗时另列，不伪装成自然线上延迟。

服务器运行：

```bash
source scripts/env_new_server.sh
"$W2_CORE_PY" scripts/v431_r5_statistics.py
```

输出 `results/v431-r5/statistics/report.json`，保留输入 SHA。可在 root 合并旧强基线后重新统计；不改变任何已冻结策略或决策轨迹。

Bolt 收益向量平方误差从 5.130355 降到 5.129511；TimesFM 从 1.212782 降到 1.203550，但后者 MASE 退步，说明不能将评分误差性质等同于治理排序或任务收益。DEV 312 个、金融 24 个完整投影案例的带 `2*gap` 余项不等式检查未发现超过 1e-8 的违反。DEV Bolt 14 个、TimesFM 15 个完整投影达到迭代上限，最大 gap 分别 0.002538382、0.004460113，均如实保留为近似解。

FULL 对 RAW 只改变五个 DEV 窗口的动作。Bolt 的两窗改善均来自同一个 `ETTm1:44624:45328` parent，Native→FFILL，每窗差 −0.150782 MASE。TimesFM 的三个变化均为退步：Solar H96 +0.057484；同一个 USTS parent 的 H96 +0.002242 与 H192 +0.000057。样例及原始评分、投影评分、gap 保存为 `results/v431-r5/statistics/fixed_trace_changed_windows.json`。结果集中于少数 parent，不能描述为广泛稳定改善。

完整自适应 R5 高预算中，Bolt 与自身免费参考及 RAW 的预测相同；TimesFM 比 RAW 差 0.001853 MASE、比 r4/免费参考差 0.004845。因此本轮不满足两家族强简单对照与另一家族几何不退步的开发门槛。
