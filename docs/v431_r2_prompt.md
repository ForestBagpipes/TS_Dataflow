## 四、实现证据状态一致的完整 agent

核实现有五臂的实际语义。固定目标变量、上下文上界、预测跨度和 TSFM checkpoint。输入治理与预测后修正分开记录。有效观测默认不可覆盖，KEEP 始终可用。

无证据状态采用在训练内选定并冻结的固定强参照。每个 TSFM 家族独立选择，不能直接根据 TimesFM 的 DEV 结果指定 ridge。

取得证据后，复用现有普通 CART 的方法和冻结规则，只读取当前实际取得的特征。历史证据、遮挡证据和完整证据对应不同可见状态，不能混用。

如果 CART 需要两个工具，就声明为两个工具的组合方案，完整计费。如果只调用一个工具，则必须使用为该可见状态训练的策略。不能让未调用工具的结果通过缓存进入决策。

本轮只保留这一套 CART 候选规则，不继续搜索模型和深度。

冻结终态策略集合后，在未参与其拟合、筛选和剪枝的训练窗口上重新生成工具价值标签。使用同一窗口取证前后实际终态策略的下游损失差，再扣除既有权重下的完整部署成本差。

不能用最优臂 oracle、旧 scorer 或证据本身的预测误差替代工具价值。

费用包含工具、最终治理和最终预测的变化，共享计算去重。预算检查整个分支需要的费用。沿用登记的预算和成本权重，不降低停止阈值来人为制造调用。

首版最多一次取证决策，组合方案内部调用多少工具就记录多少。只有预计净收益为正且预算允许时取证，否则提交当前终态动作。

如果修正后全部 STOP，结果应与固定参照一致。这是工程正确性，不能算研究贡献。
