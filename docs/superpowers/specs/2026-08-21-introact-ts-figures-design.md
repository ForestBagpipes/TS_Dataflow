# IntroAct-TS 中文图1与图2设计说明

## 目标

为论文生成两张中文矢量图：图1是示例图，图2是系统框架图。每张图均交付高清 PNG 和可编辑 PPTX，并额外提供一个两页合并版 PPTX。

## 统一视觉规则

- 白色背景、扁平学术信息图风格。
- 所有容器只用直角矩形，不使用圆角矩形。
- 所有模块基于统一网格；同级模块等高、等间距、同字号。
- 中文字体为微软雅黑，英文为 Calibri，公式为 Cambria Math。
- 颜色语义固定：数据蓝、证据青、干预橙、验收珊瑚红、反馈紫、提交绿、回滚红。
- 箭头先于节点创建，避免穿框；主流程为实线，反馈为较细回路线。

## 图1：同一编辑，不同决策

采用用户新参考图1的横向示例推演骨架：左侧为两个外观相似的峰值窗口，中间为同一去尖峰操作与沙箱副本，右侧为双信号验收结果。上行“孤立故障尖峰”显示效用改善且结构失真低，提交到治理语料；下行“真实极端峰值”显示效用改善但结构失真高，回滚并保留原窗口。图内只保留支撑该对照所需文字。

## 图2：IntroAct-TS 系统框架

采用用户新参考图2的三层结构：顶部彩色阶段条，中部详细模块区，底部治理流程带与审计轨迹。横向主流程为：原始时序语料与窗口化 → 证据获取 → 沙箱干预 → 合取验收 → 反馈与输出。第三阶段获得最大视觉权重，并明确展示 `ΔU>ε ∧ D<τ ∧ R<η`、有限样本校准得到 `τ`、COMMIT/ROLLBACK 双路径。反馈模块作为辅助闭环，不盖过验收层。

## 验收标准

- PPTX 内文字、框体、箭头、波形均可编辑。
- 无圆角矩形，无文字截断，无意外重叠，无连线穿过标签。
- 同层级字号一致，图2细节多于图1，PNG 与 PPTX 视觉一致。
