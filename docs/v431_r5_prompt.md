六、联合收益约束的数学规格

设已查询 K 个动作的预测为 p_a，参考动作编号为 0。

所有动作共用同一未来目标、同一评分权重和同一正尺度 S。

定义：

loss(p,y) = sum_h w_h * abs(p_h-y_h) / S

g_a(y) = loss(p_0,y) - loss(p_a,y)

g_0 = 0

w_h 非负且和为 1。

部署时不得读取未来 y。未来目标只用于 TRAIN 监督及正式评估。

第一层，单臂和成对距离约束。

由绝对损失的性质：

abs(g_a-g_b) <= D_ab

评分权重预先已知时：

D_ab = sum_h w_h * abs(p_a,h-p_b,h) / S

如果有效目标 mask 或评分权重需要未来标签才能确定，部署时必须使用：

D_ab = max_h abs(p_a,h-p_b,h) / S

不能通过查看未来目标哪些位置非空，偷偷得到更紧的约束。

单臂截断将原始评分 r_a 限制到：

[-D_a0, D_a0]

成对约束进一步要求：

abs(r_a-r_b) <= D_ab

这两种方法都是必须运行的简单对照。

第二层，完整联合收益可行域。

固定一个 lead h，将已查询动作在该位置的预测值依次作为折点 b。

构造 K 维向量：

v[h,b,a] =
(abs(p_0,h-b) - abs(p_a,h-b)) / S

当未知真实值 y_h 在相邻预测值之间变化时，收益向量是线性的。在最小预测值以下和最大预测值以上，收益向量保持不变。

因此，该位置所有可能收益向量的凸包，可以由上述有限折点构造。

如果评分权重在预测前已由协议固定：

C = 各 lead 折点凸包的加权 Minkowski 和

具体为：

C = {sum_h w_h*z_h :
     z_h 属于该 lead 折点向量的凸包}

如果未来有效评分位置或权重未知：

C_unknown = 所有 lead、所有折点向量的共同凸包

该集合更保守，但不需要读取未来 mask。

将原始收益评分 r 投影至相应集合：

g_hat = argmin_z 0.5 * ||z-r||²
约束 z 属于 C，且参考坐标为 0

最终选择已查询集合中校正收益最大的动作。
若最大收益不为正，保留参考动作。
并列时优先参考，其余使用预先固定的稳定顺序。

凸组合只用于构造收益可行域与求解。最终输入和预测不做混合。

理论表述必须准确。

精确欧氏投影满足：

||g_hat-g||² <= ||r-g||² - ||r-g_hat||²

其中 g 为同一查询集合的真实收益向量。

这只保证整个收益向量的平方误差不增加。
不保证每个坐标误差都降低。
不保证排序改善。
不保证最终 MASE 改善。
不构成无条件安全证书。

三角不等式、凸包、凸投影和 Frank-Wolfe 都是已有数学方法，不能宣称为本项目发明。

本轮待验证贡献是，将当前合法输入版本产生的预测转化为联合收益约束，并验证其对治理决策的增量。

七、求解器的完整实现要求

可以复用仓库已有可靠优化工具。若没有适合实现，使用 NumPy 实现带 gap 的 Frank-Wolfe。

输入：
已查询预测矩阵，形状 K×H
原始收益向量 r
正尺度 S
预先已知的评分权重，或 unknown 标记
迭代上限、数值容差和剩余时间

参考收益 r_0 必须严格为 0。

构造折点向量后，实现线性优化 oracle。

已知权重时：
对每个 lead，选择与当前方向内积最小的折点向量。
将各 lead 选中的向量按固定权重求和。

未知权重时：
在全部 lead 折点向量中选择内积最小者。

初始化 z=0。它属于上述凸集。

每步：
gradient = z-r
s = linear_minimum(gradient)
direction = s-z
gap = dot(gradient, z-s)

若 gap 达到预先登记容差，停止。

否则进行精确线搜索：
step = clip(gap / ||direction||², 0, 1)
z = z + step*direction

记录：
迭代次数
目标值
最终 gap
求解耗时
是否收敛
是否触及时间限制
异常原因

近似解应使用以下带余项的性质：

||z-g||² <= ||r-g||² - ||r-z||² + 2*gap

不能把未收敛结果标成精确投影。

求解超时、非有限输入或数值失败时，保留上一次有效决策并停止继续查询。已经发生的计算费用全部保留。

在服务器执行必要验证：
预测 0、1、2 的解析例
重复预测对应相同真实收益
已知任意 y 生成的真实收益属于对应集合
与独立小型 QP 的投影结果对照
两动作退化情况
未知未来 mask 情况
非有限输入拒绝
求解超时与回退

只有两个不同预测时，联合约束可能退化为简单区间，不能用这部分结果证明高阶结构贡献。
