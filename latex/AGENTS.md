# LaTeX 目录：显式调用的隔离审稿工作流

始终使用简体中文。继承 work2 根目录规则。本文件仅约束本目录内明确请求使用“学术论文修改协作插件”的审稿任务；普通实验、论文编辑和其他环境不自动启用该工作流。

- 入口为 `.paper-review-tool/REVIEW_ONLY.md`。采用插件安装说明的方式 A（按角色顺序编排），不注册用户或项目根 `.codex/agents`，不安装全局依赖，不激活或改动现有环境。
- 默认只审稿到问题与建议方向；不得修改任何已有 `.tex`、`.bib`、图片、PDF或实验文件，不生成可直接执行的替换稿。用户明确要求修改时也必须另行遵循冻结、评审及作者批准规则。
- 插件包内章程是被调用工作流的来源资料，原作者建设七阶段、原插件仓库与提交约定不适用于 work2，不覆盖根规则。
- 工具位于 `.paper-review-tool/vendor-v0.1.0`；每轮独立写入 `.academic-collab/runs/<run-id>`。原稿、基线及哈希须保留，已有轮次不覆盖。
- 权威账本只能由原包 `append_event` 追加；未运行时仅保存草稿，不伪造账本、完成、作者确认、全票或跨模型验证。JSON/Markdown报告不是授权记录。
- 实验、测试及工具运行验证遵守 work2 的服务器环境规定。服务器不可用时继续只读内容审查，明确工具运行未验收。
