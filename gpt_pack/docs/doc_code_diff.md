## 七 系统噪声的多通道联合注入，缺口

## 优先级建议

按改动的风险与依赖排序，与本轮给出的顺序有两处出入。

第一条 R(a) 不需要改代码，只需要补对照报告的三个口径并重跑一次
`fix_compare.py`。这是最便宜的一项，可以先做掉。

第六条分层口径需要你先裁决，因为它决定第二条金融数据接入时按几层构造语料。
在裁决之前接金融数据会做无用功。

第七条系统噪声的多通道注入与第二条金融数据接入应当合并做，因为金融语料的通道
之间存在真实联动，正是多通道系统噪声最该注入的地方，两件事共用同一条分组采样
路径。

第四条定理 6 的记录接口独立于以上各条，只加记录不改决策，随时可做。

第三条注入参数改动会触碰预注册约束，需要你先确认口径。

第五条实验档位对齐依赖第三条与第四条，放最后。
